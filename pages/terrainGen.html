Terrain Generation Project

Project Overview

The Terrain Generation Project is a tool designed to create realistic terrain using Perlin noise and a poison disc sampling algorithm for foliage placement. Genres: Unity Tool, Perlin Noise, Pseudo Random, Seeding, foilage and vegatation, Posion disc sampling
Engine: Unity
Team-Size: 1
Duration: Completed [3 months]



Technical Challenges

Some of the main things I learned from my time making this project were; how to improve my coding architecture to make the code base readable as it grew in complexity and function, when developing the terrain generation system I had to learn and incorporate some new algorithms like for the Perlin Nosie generator and the terrain object placement system.

We also looked at L-Systems during the module, while the submitted project doesn't contain a finished L-System generator it's something I plan to finish during some improvements along with collisions and chunks.

After submission I cleaned up the project finishing incomplete features and reflecting on the given feedback, it now is a much cleaner version of the submission I began working toward implementing better world generation by improving the mesh generation moving from standard Perlin noise generation to create 3D Perlin noise to allow for more detailed worlds.
