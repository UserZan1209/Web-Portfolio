!Hitman

Project Overview

!Hitman is a prototype for a stealth-assassination game that incorporates some light ragdoll mechanics. My initial idea was to have standalone levels with quests within the levels to act as ways to level up or acquire weapons unique to the level. Levels would be accessed from a base that acts as the HUB for the game that could be upgraded/ customised.

Genres: 3D, Third Person,Single Player, Survival, Souls-like, Exploration, Sci-fi, Ragdolls, Physics mechanics, Stealth
Engine: Unity
Team-Size: 1
Duration: Completed [2.5 months]



Technical Challenges

Before starting the project, I knew I wanted to add another aspect to the project to push myself and learn something new, so I decided to incorporate ragdolls into the game. My attempt at this involved using animation trees; when I wanted the character to ragdoll, the behaviour switched to ragdolls by disabling the animation controller.

The issue with this was that the transition between behaviour states was functional but was visually noticeable. After taking some time with additional research after the development period had concluded, If I were to rebuild this mechanic, I would use inverse kinematics to generate animations at runtime rather than using predetermined animations.

To finish up this project I would like to clean up the mechanics and expand on others to build a series of levels to make a small V-Slice. Most notable improving the environments making them more interactable to better integrate with the ragdoll mechanic currently present.

I would also like to do a little world building to make the game more cohesive experience. The game would be set in a dystopian future where society is fully made up of machines.

Important & Key mechanics

• Physics based gameplay and Ragdoll behaviour,
• Quest system
• Data persistence with player prefs and some experimenting with JSON format
